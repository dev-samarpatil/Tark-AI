# UI Designs & Prototypes

This directory contains the original UI/UX reference screens and HTML prototypes for the **Tark AI Assessment Cockpit**:

## Screen Prototypes

1. `tark_ai_technical_assessment_cockpit/`
   - Main cockpit layout: candidate session header, split pane code editor, and live test execution dashboard.
2. `ai_assisted_coding_workspace/`
   - Interactive IDE workspace with terminal output, test case validation, and real-time candidate telemetry.
3. `ai_decision_trail/`
   - Chronological audit log of AI suggestions, candidate accepted diffs, prompt interactions, and problem-solving milestones.
4. `evidence_linked_skill_report/`
   - Comprehensive candidate evaluation summary with radar charts, competency scoring, and code evidence links.
5. `terminal_precision/`
   - Terminal execution and test assertion diagnostic view.
